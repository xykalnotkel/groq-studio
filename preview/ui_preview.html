Yang sudah jadi

Project Flutter lengkap di folder groq-studio/, siap dibuka di VS Code / Android Studio atau dibuild APK-nya lewat GitHub Actions.

  • 12 mode generate (judul, artikel, penjelasan aplikasi, Play Store, caption + hashtag, ide nama, catatan rilis, copy iklan, email, brainstorming, prompt bebas)
  • Streaming kata demi kata + tombol hentikan
  • Bahasa, gaya, dan panjang hasil bisa diganti di dalam aplikasi
  • Daftar model ditarik langsung dari akun Groq kamu
  • Riwayat tersimpan di HP, bisa dicari & difavoritkan
  • Salin & bagikan sekali ketuk, tema gelap/terang

Jalanin di laptop

cd groq-studio
flutter pub get
flutter run --dart-define=GROQ_API_KEY=gsk_xxxx

Build APK

flutter build apk --release \
  --dart-define=GROQ_API_KEY=gsk_xxxx

# atau biarkan GitHub Actions yang kerjakan
git tag v1.0.0 && git push --tags

Yang bikin UI-nya "hidup"

  • Blob gradien di latar yang bentuknya berubah terus
  • Tombol utama menyusut jadi lingkaran stop saat streaming
  • Perpindahan kosong → loading → hasil pakai morph (fade + scale)
  • Kartu mode membesar & membulat saat dipilih
  • Transisi halaman fade + slide, ikon mode terbang (Hero) Riwayat → Detail
Catatan: tampilan di atas hanya preview statis (HTML). Aplikasi aslinya ada di source Flutter — hasil generate baru benar-benar jalan setelah kamu memasukkan API key Groq gratis dari console.groq.com/keys.
